## 📌 About the Repository

Welcome to my NLP Assignments Portfolio. This repository showcases a series of 4 comprehensive projects completed as part of my Natural Language Processing course. The projects demonstrate a progression from fundamental text preprocessing and classical machine learning to advanced deep learning architectures and state-of-the-art Transformer models with model interpretability.

## 🚀 Projects Showcase

| Assignment | Project Title | Key Focus | Tech Stack |
| :--- | :--- | :--- | :--- |
| **01** | [**Text Preprocessing Pipeline**](./Assignment-1-Text-Preprocessing/) | Text Cleaning · Roman Urdu Normalization · Intent Classification | `NLTK`, `Scikit-learn`, `Gradio` |
| **02** | [**Tokenization & Stemming Analysis**](./Assignment-2-Tokenization-and-Stemming/) | Feature Engineering · Deep Learning Comparison (LSTM/RNN) | `TensorFlow`, `Keras`, `LSTM` |
| **03** | [**Sentiment Analysis**](./Assignment-3-Sentiment-Analysis/) | Rule-based vs ML · Sentiment Classification · Evaluation | `NLTK`, `VADER`, `Scikit-learn` |
| **04** | [**Advanced Text Classification**](./Assignment-4-Text-Classification/) | DistilBERT Fine-tuning · Explainability (SHAP/LIME) | `HuggingFace`, `PyTorch`, `SHAP` |

## ⚙️ Installation & Setup

To explore these projects locally, follow these steps:

### 1. Clone the Repository
```bash
git clone https://github.com/zohairmaken/NLP-assignments-Semester.git
cd NLP-Assignments
```

### 2. Create a Virtual Environment
```bash
python -m venv venv
# Windows
.\venv\Scripts\activate
# Linux/Mac
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```
